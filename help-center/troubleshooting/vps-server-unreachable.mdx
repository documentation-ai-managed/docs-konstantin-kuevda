---
title: VPS Server Unreachable
description: How to fix if your SkyITVPS server is not responding.
---

## Symptoms

- Cannot access server via RDP/SSH
- Ping/connection fails

## Causes

- Network misconfiguration
- Firewall rules
- Resource overload

## Quick Fix

<Steps>
  <Step title="Check Network">
    ````bash
    ping your-vps-ip
    ````
  </Step>
  <Step title="Restart Server via Panel">
    Use your SkyITVPS dashboard "Restart" button.
  </Step>
  <Step title="Contact Support">
    If issue persists, email support@skyitvps.com.
  </Step>
</Steps>
