## Quick Start

Get your server running in under 10 minutes:

<Steps>
  <Step title="Sign Up" icon="user-plus">
    Create your account at `https://dashboard.skyitvps.com/register` and verify your email.
  </Step>
  <Step title="Choose Plan" icon="credit-card">
    Select a VPS or cloud plan suited for accounting workloads, starting from basic to enterprise tiers.
  </Step>
  <Step title="Deploy Server" icon="rocket">
    Pick an OS image (Linux/Windows) and launch. Access via SSH or RDP immediately.
  </Step>
  <Step title="Connect Securely" icon="terminal">
    Use the provided IP and credentials to connect.
  </Step>
</Steps>

<CodeGroup tabs="Linux,Windows">
  ```bash
  ssh root@YOUR_SERVER_IP -p 22
  # Enter password: YOUR_ROOT_PASSWORD
  ```
  ```powershell
  mstsc /v:YOUR_SERVER_IP
  # Use RDP credentials provided
  ```
</CodeGroup>
