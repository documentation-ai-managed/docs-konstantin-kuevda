## Access and Verify Your Server

Retrieve SSH credentials from the dashboard under `My Servers > Actions > Console`.

<CodeGroup tabs="Linux,macOS,Windows">
  ```bash
  # Linux/macOS
  ssh root@your-server-ip -p 22
  # Enter password from dashboard
  whoami  # Should output: root
  uptime  # Verify server is running
  ```
  ```powershell
  # Windows (PowerShell)
  ssh root@your-server-ip -p 22
  # Use PuTTY or OpenSSH
  whoami
  uptime
  ```
</CodeGroup>

Run `apt update && apt upgrade -y` (Ubuntu) to secure your instance.

## Basic Security Setup

Enable firewall and update packages immediately.

```bash
ufw allow OpenSSH
ufw --force enable
ufw status
```
